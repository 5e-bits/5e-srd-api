## Preparing Your Bash Adventure

Before we set off on our coding journey, make sure you have these:

1. A command-line terminal (Bash)
2. An internet connection
3. Your excitement and curiosity

## Building the D&D Species Search Tool

1. **Summon the Magic of Curl:**

    Open your command-line terminal and let's cast our first spell to fetch D&D species information using the mighty `curl` command. Type or copy-paste the following:

    ```bash
    curl -L 'https://www.dnd5eapi.co/api/2024/species/dwarf' -H 'Accept: application/json'
    ```

    When you hit Enter, you'll unveil the details of the D&D Dwarf species!

2. **Create Your Own Spell (Bash Script):**

    Now, let's create a magical script named `dnd_species_search.sh` using your favorite text editor (like `nano`, `vim`, or even a code editor).

    ```bash
    #!/bin/bash

    echo "Welcome to the D&D Species Search Tool!"
    echo "-----------------------------------"
    echo

    read -p "Enter the name of a D&D species: " species_name

    curl -L "https://www.dnd5eapi.co/api/2024/species/$species_name" -H 'Accept: application/json'
    ```

3. **Enchant Your Script:**

    Before you can use your script, you'll need to make it executable (aka runnable). In your terminal, type:

    ```bash
    chmod +x dnd_species_search.sh
    ```

4. **Embark on Your Quest:**

    Cast your spell and run your script:

    ```bash
    ./dnd_species_search.sh
    ```

    You'll be prompted to enter the name of a D&D species. For now, let's try "dwarf" and see what magnificent details unfold!
